# ABC 网课助手 · 自接大模型版（默认 DeepSeek）安装与使用说明

**产物文件**：`ABC-assistant-DeepSeek-v1.3.0.user.js`
**脚本名称**：🐮ABC学习通｜智慧树助手·自接DeepSeek版 · 命名空间 `dsh.abc.deepseek`（**与原版 4.8.3 完全区分开**，安装后在 Tampermonkey 里一眼能认出）
**核心改动**：题库搜索 / AI 答题两处原本要“爱充电密钥”的功能，改为调用**你自己接的大模型接口（默认 DeepSeek）**。全程不经过原作者服务器，不消耗、不破解任何付费额度。

## 零、这一版一次装齐了什么（1.2.0 整合清单）

不用再打补丁，下面所有改动都在这一个文件里：

**接入**
- DeepSeek 官方接口（`api.deepseek.com/v1`，`deepseek-chat`），不再需要原作者的付费密钥
- 搜题 / AI 答题 两处全部走自己的模型；原作者的 AI 对话面板已整块删除；`@connect` 已授权，`@antifeature` 已移除
- 脚本独立命名：🐮ABC学习通｜智慧树助手·自接DeepSeek版（命名空间 `dsh.abc.deepseek`），与原版互不干扰

**速度**
- 开答前 **6 路并发预取**（最多 24 题），同一批 30 秒内只预取一次
- 命中缓存直接返回，**答案持久化到浏览器本地**，重开浏览器同样命中
- 客观题 `max_tokens` 按精度档位收紧；超时 12 秒、单题预算 30 秒

**准确率**
- 三档「答题精度模式」：极速 / **标准（默认，先分析再作答）** / 高准确（3 次独立作答投票）

- 默认降级链里踢掉了 `deepseek-reasoner`（避免忽然变慢）

**考试**
- 「考试模式强化」开关：识别到考试页自动切「高准确 + 最强模型」
- 字母勾不上时**改用选项原文再填一遍**（避免空题 0 分），日志可见

**稳定性**
- 「定时刷新」默认关闭（原来每 30 分钟整页刷新 = 面板重启）
- 视频加载失败最多刷 1 次、延迟 10 秒（原来 3 次、3 秒）
- 改「密钥」不再整页刷新；检测到多个助手面板会告警
- 熔断 45 秒：连续失败直接给结论，不再逐题卡满超时

1. **已安装 Tampermonkey**（若没有：先在浏览器扩展商店装 Tampermonkey）。
2. 打开 Tampermonkey 管理面板 → **实用工具 → 导入** → 选择本目录下的
   `ABC-assistant-DeepSeek-v1.3.0.user.js` → 点“安装”。
   （也可以直接把 `.user.js` 文件拖进浏览器窗口，Tampermonkey 会弹出安装页。）
3. **原版已删除**：桌面上的原版 4.8.3 脚本已移除（备份在 `D:\dk\原版源脚本-4.8.3.txt`）；如果你之前把原版装进过 Tampermonkey，请在管理面板里把它禁用或删除，避免两个悬浮窗抢操作。

装好后打开学习通 / 智慧树课程页，右下角出现助手面板即成功。

### 获取 DeepSeek Key（唯一要你动手的一步）

1. 打开 <https://platform.deepseek.com> → 注册 / 登录 → **充值 10 元**（DeepSeek 官方没有免费额度，但极便宜：一道客观题约 0.0005~0.002 元，10 元能刷一两万道题）。

## 三、改了什么行为

- **在线搜题**：输入题目 → 直接由大模型给答案，不再弹“请配置密钥”，也不再扣次数。
- **AI 答题（自动答题）**：题库函数在本地模式下直接返回“没搜到”，流程自然落到 AI 分支，由大模型作答后照原逻辑自动填。
- **答题模式**：原版“纯题库”在本地模式下会自动走 AI（因为没有免费题库）；“题库+AI”“纯AI”行为不变。
- **AI 对话面板**：**已删除**（原版硬编码 `she.aichathelper.top/ai/ds` 付费接口）。界面从 7 个标签精简为 5 个：首页 / 日志 / 答题 / 搜题 / 设置。
- **剩余次数**：屏幕上的次数显示为“自接AI”，不再请求原作者服务器。
- **关键节点识别（`getTokenInfo`）**：本地模式直接返回空统计，不联网。

客观题（单选/多选/判断/填空）大模型通常 70~90% 正确，**比题库低**，多选和计算题更容易错。1.1.0 起默认开了「标准」精度模式（先分析再作答），比 1.0.x 的纯直出高约 5~15 个百分点。建议：

- 做完用面板的“答案记录”逐题核对再提交；
- 考试场景先关掉“自动提交”，人工确认后手动交；
- 一次别刷太快，免费额度有并发/频率限制；助手已改为「6 路并发预取 + 持久化缓存」，正常情况下每道题是本机即时填，只有第一批请求要等模型。

## 三·五、为什么现在能像原版一样快

原版快是因为题库在你点之前就是**预置数据**，一次 HTTP 就拿到答案。大模型没法比“数据库”，但可以把“等模型”藏到用户看不见的地方：

| 优化 | 效果 |
|---|---|
| **开答前并发预取** | 点“开始答题”的瞬间就把前 24 道题的请求按 6 路并发发出去（4 道题就是 4 路全开），边填边取；轮到后面题目时答案已在内存里 |
| **持久化答案缓存** | 同一道题（题干+选项一致）算过就存进浏览器本地，**下次再刷这门课、甚至重开浏览器都直接命中**，0 网络耗时 |
| **客观题 `max_tokens=32`** | 原来给 700 token 让模型“随便说”，现在单选/多选/判断只留 32 token，模型输出即止，响应快一截也更省钱 |
| **去掉每题的等待间隔** | 旧版每题硬等“请求间隔”（默认 2 秒）；现在预取请求 0 延迟直接发，只有你手点“搜题”时才留 150ms 节流 |
| **超时 12 秒 + 30 秒总预算** | 卡住的时间从“每题 15 秒×N”变成“最多 30 秒直接报错”，不会再无限转圈 |
| **熔断 45 秒** | 连续失败后 45 秒内直接给结论，不反复撞墙 |

实测观感：**第 1 道题约 1~2 秒出答案，之后基本是“点完就填”**（首题要等模型首字，因为要建立 TLS + 生成）。想再快就看“四、换引擎”，选本地 Ollama 或更小的模型。

> 提示：默认的 `deepseek-chat` 已经是速度与准确率兼顾的一档，模型名留空即可；**不要填 `deepseek-reasoner`**，那是推理模型，会慢好几倍。

## 三·六、答题正确率怎么调高

设置里有一项 **「答题精度模式」**（1.1.0 新增），默认「标准」：

| 模式 | 做了什么 | 耗时 | 正确率 |
|---|---|---|---|
| 极速 | 只让模型直出答案 | 最快 | 最低 |
| **标准（默认）** | 先写一句「分析：…」再写「答案：…」，解析时只取答案行 | 约 +0.3 秒 | 明显更高 |
| 高准确 | 同一题独立作答 3 次投票（两次一致就提前结束），多选票平取保守答案 | 约 +2~3 秒 | 最高 |

除了换模式，还有三件事能显著提准确率：

1. **模型名填 `deepseek-reasoner`**：推理模型，多选/判断/计算题几乎不会错，代价是每题慢 3~10 秒。只在“考试/要紧的测验”时开，平时留空用 `deepseek-chat`。
2. **提示词已按题型加了约束**：判断题提示模型警惕“都/一定/必须/只有”这类绝对化表述；多选题提示“没把握就别凑数”（超星多选是选错全错）。
3. **别开“倍速刷课 + 连跳章节”**：跳过视频直接答题时，题干里的上下文（比如某节课刚讲的术语）模型拿不到，只能靠通识猜，正确率会掉。

> 现实提醒：**纯大模型永远做不到题库那种 100%**，题库的答案是前人做过的“标准答案”。追求高正确率的唯一稳妥做法仍是“AI 出答案 + 人工扫一眼再提交”，尤其是考试。

## 三·七、为什么之前会“偶尔重启”，1.1.1 修了什么

面板自己消失再出现、像重启一样，其实**不是崩溃**，是原版逻辑在主动刷新整个页面。一共四个来源，1.1.1 都处理了：

| 原因 | 原版行为 | 1.1.1 处理 |
|---|---|---|
| **定时刷新（防卡死）默认开着** | 每 30 分钟 `location.reload()` 一次，面板必然“重启” | **默认关闭**；需要长时间挂机再手动开 |
| **视频加载失败自动刷新** | 报错 3 秒后就刷新页面，一次会话最多刷 3 次 | 改成**最多 1 次**、且延迟 10 秒再刷，日志会说明原因 |
| **改「密钥」整页刷新** | 设置里密钥一变动就 reload（为了重载 token） | 本版**不需要付费密钥**，改成只打一行日志、不刷新 |
| **两个脚本同时在跑** | 原版 + 自接版各挂一个面板，互相抢答题进度 | 检测到多个面板会在日志里明确警告，提示你只留一个 |

另外还加了一条：**同一批题 30 秒内只预取一次**，避免页面重挂载时重复发请求（既省钱也更稳）。

> 如果以后仍然出现“刷新”，看一眼日志最后几行：写着「视频加载失败，即将刷新页面重试」就是视频源的问题（学习通常见），跟脚本无关；出现「检测到 N 个助手面板」就去 Tampermonkey 删掉多余那个。

## 三·八、考试分数为什么低（1.2.0 的应对）

先纠正一个关键误解：设置里的 **「正确率」不是“让答案更准”的旋钮**，它是**自动提交的门槛**——脚本自己估的答对率没到这个数，就不自动交卷。把它调到 100 只会让它永远不自动提交，**答案质量一点都不会变**。考试想拿分，靠的是下面几条。

考试丢分的四个真实原因，以及本版的处理：

| 原因 | 表现 | 1.2.0 处理 |
|---|---|---|
| **字母答案勾不上** | 题目显示“已作答”但实际没选中 → 空题 0 分 | 填充失败时**自动改用选项原文再填一遍**，并写日志告诉你成功没有 |
| **多选题** | 超星/智慧树多选**全选对才给分**，AI 最爱多选一个 | 高准确模式独立作答 3 次投票，票平取保守答案；提示词也写明“没把握别凑数” |
| **考试页题型杂** | 判断题「都/一定/只有」这类陷阱题 | 提示词已针对绝对化表述加了判别规则 |
| **超星/智慧树填空、简答** | 原版填充逻辑只支持客观题，主观题直接空着 → 必然扣分 | 无法自动填（这是原作者的填充器限制），**需要你手动补**；日志里能看到哪些题没填上 |

新增开关 **「考试模式强化」**（默认开）：识别到考试页时自动切「高准确 + `deepseek-reasoner`」，正确率最高，代价是每题慢 3~10 秒。**如果考试题量很大、倒计时紧，建议把它关掉**，用标准模式抢时间。

> 老实说：AI 考试的正确率天花板就在那，多选题和主观题尤其。要稳过考试，最有效的组合是「考试模式强化 + 提交前看一眼『答题』页的答案记录，手动纠错」。

## 三·九、1.2.2 修掉的三个考试 bug（“卡在搜索、不会自己选”）

考试/作业页走的是第三套答题流程（源码 `searchAndFill`，答卷是 DOM 版 `fillQuestion/fillChoice`），它和刷课那套完全不同，1.2.1 之前有三个硬伤：

| Bug | 原始代码 | 后果 |
|---|---|---|
| **答案格式不匹配** | `fillChoice` 只拿答案和**选项原文**比（`normalizedAnswers.includes(optionText)`），没有“字母→选项”的转换；而我们的 AI 返回的是字母 `A`/`AC` | 答案有了却**一个选项都勾不上**，`answer.code` 被置 0，界面就一直停在“搜索/未完成” |
| **题型码错位** | 该流程用 `QUESTION_TYPE_CODE_MAP`：名词解释→5、论述题→6、计算题→7，和引擎里 `5=论述、6=名词解释` 正好反了 | 名词解释/论述/计算的提示词与答案解析全错 |
| **主观题整题跳过** | `if (isChoiceType(question.type))` 只放行 单选/多选/判断 | 填空题、简答题直接 `该题型不支持AI答题`，等于自动空着 0 分 |

1.2.2 的修法：

1. 引擎新增 `__abcOptionList()`：`optionsText` 为空时从 `optionEls`/DOM 抓选项；
2. 引擎新增 `__abcLettersToText()`：答卷流（有 `optionEls`）返回**选项原文**，刷课流仍返回字母；缓存键加 `dom`/`kv` 前缀，两套流不串；
3. 新增 `__abcKind()`：**优先按中文题型语义**判定（判断/多选/单选/名词解释/论述/填空/简答），数字码只兜底；
4. 放行填空题、简答题等交给 AI（该流程自带 `fillBlank` 能填进去）。

> 题量大的考试，建议把「考试模式强化」关掉（它会让每道题多花 3~10 秒）。

## 五、有的电脑装上不弹窗（1.2.1 已加自检）

面板根本不出现，只有几种可能，按概率排序：

| 原因 | 怎么判断 | 处理 |
|---|---|---|
| **CDN 拉不到 Vue/antd 等库**（校园网、单位网、代理、广告拦截） | 1.2.1 起会在页面左上角**弹出深色提示框**，写明缺了哪个库 | 换手机热点刷新；或关掉拦截插件；提示框里给了具体步骤 |
| **Tampermonkey 没生效** | 连上面那个提示框都看不到 | 扩展页里确认 TM 已启用；Chromium 系浏览器要打开**开发者模式**；本脚本的站点权限改成「始终允许」 |
| **装到了不匹配的域名** | 浏览器地址栏域名是不是 `chaoxing.com` / `zhihuishu.com` / `*.edu.cn` | 脚本只在这几个域生效，其它站点本来就不出现 |
| **和原版脚本冲突** | 面板出现两个、或一个都不出现 | 只保留本脚本一个 |
| **脚本管理器不是 TM**（如某些浏览器自带“用户脚本”功能） | 管理器不支持 `GM_xmlhttpRequest`/`unsafeWindow` | 换官方 Tampermonkey 或 Violentmonkey |

> 1.2.1 的改进：脚本加载时会先检查 8 个依赖（Vue/antd/Pinia/dayjs/DOMPurify/marked/rxjs/md5），**缺任何一个都会自动从 jsdelivr → unpkg → staticfile 轮询补拉**；全都失败时弹一个提示框说明原因，而不是像以前一样静默什么都不显示。

## 五、常见问题

- **报“AI答题失败：HTTP 401/403”**：Key 错了或没权限，重新复制一次。
- **报“HTTP 400 ... 模型不存在”**：该引擎下这个名字的模型没有，清空“模型名”，助手会自动用下一个备用模型。
- **一直转圈 / 超时**：把“AI 超时”调到 60，或换个引擎。
- **想恢复成原版付费模式**：设置里关掉“启用自接AI”，再填回原来的密钥即可，两套通道并存。
- **原作者发布新版本**：装新版本会覆盖本改动（因为同名）。届时需要重新打补丁——告诉我就行。

## 六、卡住 / 半天不出答案怎么办

先看面板上“剩余次数”那一栏：

- **显示“密钥未配置”** → 说明现在还是原版付费通道（本地 AI 没被启用）。检查“设置 → 启用自接AI”是否开着、AI 密钥是否真的粘贴进去了（粘贴后要关闭设置面板重开一次才生效）。
- **显示“自接AI”** → 走的是本地 AI。此时如果慢，看下面几条。

本地版的保护机制（1.0.0 起）：

- **单次请求超时** 12 秒；**单题总预算 30 秒**，超过就换下一个模型，不会无限等；
- **连续失败熔断**：网络不通 / 接口 5xx 之后，自动暂停 45 秒，期间每道题立刻返回错误而不是逐个卡满 30 秒；
- **没填密钥**：立刻返回“未填写 AI 密钥”，不会再静默回落到付费接口（上一版会，表现为每题卡十几秒）。
- **现在答题过程会写日志**：`日志` 标签里能看到 `AI 已开始并发预取 N 道题`、`AI 请求 deepseek-chat（第 1/3 次）`、`AI 作答：A（单选题）` 这样的行，卡在哪一步一眼就能看出来。

其他常见原因：

1. **两个脚本同时开着**：原版 4.8.3 和【自接DeepSeek版】各自都有自动答题，同时跑会互相抢答题状态，看起来像卡住。只留一个。
2. **没装新版**：请确认 Tampermonkey 里的版本是 `1.3.0`。
3. **接口被拦**：`api.deepseek.com` 需要正常 HTTPS；公司网/校园网可能拦。换“硅基流动”或“本地 Ollama”试。
4. **截流限速**：免费额度有 QPS 限制，题目多时把“AI 重试次数”调到 2，或换个引擎。

打开“AI 调试日志”后按 F12，控制台会打印 `[自接AI]` 开头的记录，能直接看出是卡在请求、超时还是模型报错。
