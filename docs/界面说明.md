# 界面说明（1.3.0）

面板从原版的 7 个标签精简为 **5 个**：首页 / 日志 / 答题 / 搜题 / 设置。

| 标签 | 用途 |
|---|---|
| **首页** | 版本与快捷入口；开启「视频」「答题」两种协助模式的开关 |
| **日志** | 运行日志。答题、AI 请求、失败原因、熔断、重复面板告警都在这里，**排障先看这里** |
| **答题** | 当前页面解析到的题目列表、每题状态（搜索中 / 已作答 / 失败）、答案记录 |
| **搜题** | 手动粘题干直接问模型（本地模式不扣次数） |
| **设置** | 分「基本设置 / 考试设置 / 超星设置」三组，见下 |

## 相比原版删掉的东西

- **AI 对话**：原版把聊天请求发往作者自己的 `she.aichathelper.top/ai/ds`（要付费 token）。本项目**整块删除**该组件，不再有任何指向作者服务器的请求。
- **刷课队列**：原版用来排队刷多门课的页面，删掉后仍是“单页自动刷”，不影响视频/答题主流程。

## 设置分组里你会用到的项

| 项 | 默认 | 说明 |
|---|---|---|
| 启用自接大模型 | 开 | 总开关，关掉才回到付费密钥通道 |
| AI 引擎 | DeepSeek | 也可换智谱/硅基流动/百炼/Gemini/本地 Ollama/自定义 |
| AI 密钥 | 空 | 自己的 Key，只存在本地浏览器 |
| 模型名 | 空 | 留空用默认（`deepseek-chat`）；填 `deepseek-reasoner` 更准但更慢 |
| 答题精度模式 | 标准 | 极速 / 标准 / 高准确（3 次投票） |
| 考试模式强化 | 开 | 识别考试页自动切高准确 + 最强模型 |
| AI 重试次数 / 超时 / 调试日志 | 1 / 12s / 关 | 排查时把调试日志打开，F12 有 `[自接AI]` 明细 |
| 答题模式 | 题库+AI | 自接模式下“纯题库”也会走 AI |
| 定时刷新 | **关**（本版改） | 原版默认开，每 30 分钟整页刷新会让面板“重启” |

## 日志长什么样

正常答题时你会看到（1.1.0 起）：

```
AI 已开始并发预取 4 道题（并发 6）
AI 请求 deepseek-chat（第 1/3 次）
AI 作答：A（单选题）
AI 作答：正确（判断题）
```

出问题时看关键词：`AI 作答失败：`（带具体 HTTP 错误）、`已暂停 45 秒`（熔断）、
`检测到 N 个助手面板`（装了多份脚本）、`视频加载失败，即将刷新页面重试`（跟脚本无关）。
