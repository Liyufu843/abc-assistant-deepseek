# 更新日志

## 1.3.0
- 界面精简（破坏性变更）：移除「AI 对话」标签页并整段删除该组件（其中硬编码原作者 `she.aichathelper.top/ai/ds` 接口），
  同时移除「刷课队列」标签页；面板只剩 首页 / 日志 / 答题 / 搜题 / 设置。
- 移除 `@connect aichathelper.top` 授权。
- 体积从 710 KB 降到 694 KB。

## 1.2.2
- 修复考试/作业答卷流三处硬伤：
  - 答卷按“选项原文”比对，引擎却返回字母 → 新增 `__abcLettersToText`，答卷流自动转原文；
  - 题型码错位（名词解释/论述/计算）→ 新增 `__abcKind`，优先按中文题型语义判定；
  - 填空题/简答题被整题跳过 → 放行给 AI（该流程自带 `fillBlank`）。
- 缓存键区分 `dom`/`kv` 两种答卷流，避免串用。

## 1.2.1
- 新增依赖自检外壳：缺库时从 jsdelivr → unpkg → staticfile 补拉，全失败弹可见提示框（原先静默无面板）。

## 1.2.0
- 新增「考试模式强化」：识别考试页自动切高准确 + 最强模型。
- 字母勾不上时自动改用选项原文重填，并写日志。

## 1.1.1
- 稳定性：定时刷新默认关闭；视频失败最多重刷 1 次且延迟 10 秒；改密钥不再整页刷新；多面板告警。
- 预取去重：同一批题 30 秒内只预取一次。

## 1.1.0
- 新增「答题精度模式」三档（极速/标准/高准确），标准模式先分析再作答。
- 客观题 `max_tokens` 从 32 提到 200，修掉“被截断导致答错”。
- 降级链剔除 `deepseek-reasoner`，避免忽然变慢。

## 1.0.1
- 并发预取 3→6 路、预取上限 12→24 题、预取零延迟、答案持久化到 localStorage。
